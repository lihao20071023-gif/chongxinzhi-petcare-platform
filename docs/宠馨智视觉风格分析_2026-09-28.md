# 宠馨智视觉风格分析

分析对象：用户提供的14张同类宠物产品界面截图。

分析边界：只拆解视觉基调、布局逻辑、留白策略、信息密度和组件组织方式；不复制品牌、吉祥物、具体文案或业务组件。

## 一、总体判断

截图共同呈现出高明度青绿、浅蓝、浅草绿，大圆角、柔和阴影、明显主按钮和宠物角色陪伴感。该方向适合降低宠主使用医疗工具时的紧张感，但截图中大量社区、会员、商城、娱乐玩法和高饱和3D角色不适合直接进入宠馨智的医疗护理主流程。

宠馨智适合采用：温暖可靠、专业不冰冷、宠物医疗感。

宠主端保留暖米色底、薄荷绿主色和少量宠物陪伴元素；医生端沿用相同圆角与留白语言，但以医疗蓝为主、减少插画、提高病例和风险信息密度。

## 二、结构化拆解

### 1. 主色调倾向

截图特征：高明度青绿、浅蓝、浅草绿；部分娱乐页面使用深蓝黑。

宠馨智适配：宠主端使用低饱和薄荷绿，医生端使用医疗蓝，页面背景使用暖米白。深蓝黑娱乐风格不进入医疗主流程。

### 2. 辅助色用法

截图特征：黄色、橙色用于活力和促销，粉色用于情感标签，红色用于强调。

宠馨智适配：黄色只作温暖提示；红色只用于真实风险、失败和紧急状态；不使用促销型彩虹配色。

### 3. 字体与字号层级

截图特征：标题粗黑、正文常规，功能卡标题较大，辅助说明为灰色。

宠馨智适配：一级标题22–24px，卡片标题15–17px，正文14–16px，辅助信息不低于11pt设计基线。数字和风险状态可以加粗，但不能与主操作争夺注意力。

### 4. 行高

截图特征：说明文字行距较宽；表单行保持单行并提供较大的触控面积。

宠馨智适配：正文行高1.55–1.7，表单行最小56px。医疗说明和医生来源信息不能压缩成难以阅读的小字。

### 5. 间距体系

截图特征：页面左右留白明显，模块间距大于模块内部间距。

宠馨智适配：采用4/8/12/16/24/32间距体系；移动端左右16px；核心区块间距24px；同组控件间距8–12px。

### 6. 圆角规范

截图特征：弹窗、输入框和功能卡普遍使用大圆角，按钮胶囊化。

宠馨智适配：主卡16px，弹层24px，输入框12px。胶囊形只用于标签和主按钮，避免所有组件都过度卡通。

### 7. 卡片形态

截图特征：白色卡片叠在浅色背景上，边框较弱、阴影柔和；内容卡通常一图一标题。

宠馨智适配：白卡、细边框、轻阴影；一张卡只承载一个任务或一个状态，不能把十几个功能塞进一张大卡。

### 8. 按钮样式

截图特征：主按钮使用高饱和青绿并接近通栏，次按钮使用灰白色。

宠馨智适配：每屏一个主按钮；危险动作使用红色；次操作使用描边或文字按钮；点击区域不小于44px。

### 9. 页面布局范式

截图特征：顶部大视觉区，下方功能宫格；建档页使用纵向单列表单；AI页使用对话输入与推荐问题。

宠馨智适配：首页改为“宠物身份、今日护理、记录入口”三个核心区；建档和健康记录保留纵向单列；AI页降低角色插画占比，优先展示宠物、医生方案和问题输入。

### 10. 信息密度

截图特征：社区和工具页面差异较大；功能宫格页面密度高，建档和空状态页面密度低。

宠馨智适配：整体保持中等偏疏，每屏不超过三个核心任务点；低频功能进入二级目录，不在首页平铺。

## 三、可复用的设计特征

1. 暖色或浅色背景承接焦虑用户。
2. 大圆角与柔和阴影降低医疗距离感。
3. 纵向单列表单降低首次建档难度。
4. 空状态直接给出下一步主操作。
5. AI入口使用明确提问框和推荐问题。
6. 底部导航保持五个稳定入口。

## 四、不适合直接带入宠馨智的特征

1. 社区瀑布流、创作和宠物穿搭玩法。
2. 会员成长值、虚拟能量、邀请奖励和促销商城。
3. 大量3D吉祥物占据医疗信息区域。
4. 使用高饱和渐变包装“智能诊断”。
5. 无证据的24小时诊断或精准诊断承诺。
6. 一屏十几个同权重功能入口。

## 五、项目适配结论

截图的浅色底、大圆角、低压迫表单、明显主按钮和宠物陪伴感适合宠主端。医生端可以继承圆角、留白和组件一致性，但需要提高病例、异常和处理状态的信息密度，并减少娱乐化插画。

宠馨智最终视觉方向：暖米色底，宠主端薄荷绿，医生端医疗蓝；宠物元素传递陪伴感，医疗数据保持克制和清晰；AI相关页面固定标注“不诊断、不改药”。
