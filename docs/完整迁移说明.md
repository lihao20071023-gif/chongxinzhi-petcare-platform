# 宠馨智完整迁移说明

这个迁移包用于把宠馨智从当前 Mac 电脑完整转移到 Windows、另一台 Mac 或交给开发团队继续开发。

## 总包中包含什么

- `项目源文件/`：宠主端、医院/医生端、微信小程序、Node.js API、独立 Web 管理后台、Supabase 数据库脚本和设计资源。
- `可直接查看的页面/`：已经构建好的宠主端、医生端、系统总入口和独立管理后台。
- `对话与提示词/`：本次会话中用户提出的需求、提示词、附件引用以及助手回复。
- `外部参考素材/`：仍能找到的参考图片、视频和“宠物AI健康模版”文件夹。
- `清单与校验/`：文件列表、SHA-256 校验值和原路径已不存在的附件清单。

为了兼容 Windows，ZIP 内不包含 `node_modules`、`.next` 等可重新生成的系统缓存；它们体积很大，而且从 Mac 直接复制到 Windows 也不能可靠使用。项目依赖版本已经由 `package.json` 和 `pnpm-lock.yaml` 保存。

## 在 Windows 上先看页面

1. 将 ZIP 完整解压，不要只在压缩包预览器里双击文件。
2. 打开 `可直接查看的页面/宠主与医生端/index.html` 查看宠主端。
3. 打开 `可直接查看的页面/宠主与医生端/hospital.html` 查看医院/医生端。
4. 打开 `可直接查看的页面/宠主与医生端/portal.html` 查看系统总入口。
5. 打开 `可直接查看的页面/Web管理后台/index.html` 查看独立管理后台。

如果浏览器限制本地网页资源，可在该目录打开命令行并运行：

```text
python -m http.server 8080
```

然后访问 `http://127.0.0.1:8080/`。

## 在新电脑继续开发

1. 安装 Node.js LTS、Git 和 pnpm。
2. 进入 `项目源文件` 目录，运行 `pnpm install`。
3. 宠主/医生网页开发：运行 `pnpm dev`。
4. 统一 API：参考 `.env.api.example` 配置环境变量，再运行 `pnpm api`。
5. 独立管理后台：参考 `admin-web/.env.local.example`，运行 `pnpm admin:dev`。
6. 微信开发者工具中导入 `项目源文件/miniprogram`，配置合法域名和真实微信 AppID。
7. 按时间顺序执行 `项目源文件/supabase/migrations` 中的 SQL，建立数据库结构与权限。

## 真实上线前仍需单独配置

- 微信小程序 AppID、AppSecret 与登录回调。
- Supabase 或其他 PostgreSQL 项目地址、密钥和对象存储。
- 大模型 API 地址、模型名称与服务器密钥。
- 医院和医生真实资质审核流程。
- 隐私政策、用户授权、数据导出/撤回机制和审计日志。

真实密钥和密码没有写入迁移包。请在新电脑重新创建本地 `.env` 文件，不要把密钥上传到网盘公开链接或代码仓库。

## 不变的产品边界

医生负责诊断、治疗和用药决策；宠馨智负责把医生确认的护理方案拆成每日任务，收集家庭记录、显示趋势、标记异常并回传医生。AI 不独立诊断，不自行改药，找不到知识依据时应明确说明依据不足。
