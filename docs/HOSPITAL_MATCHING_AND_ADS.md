# 宠馨智：医院匹配与曝光产品规则

## 产品决定

该能力与“连接宠物主人和宠物医院的院外慢病管理系统”相符，但不做付费操控的综合排行榜。

产品拆成两条完全分开的通路：

1. **自然匹配**：仅在已核验医院中，按宠物种类、本次病种/需求、医院能力、急诊能力、城市和区域等因素计算。必须解释返回理由，不引用广告状态或付费额。
2. **付费曝光**：独立广告区域，显著标注“广告”，不声称更适合、更权威或疗效更好。急诊模式完全隐藏广告。

## 三端职责


### 宠物主人端

- 手动选择城市和区/县，不猜测位置。
- 默认以当前宠物的猫/犬类型和已记录病种做匹配。
- 显示“为什么匹配”和数据局限。
- 没有真实经纬度时不显示公里数和到达时间。
- 紧急情况提示立即电话确认并就近就医，不等待平台结果。

### 医院 / 医生端

- 医院自行填写真实主体、动物诊疗许可证、地址、营业时间、接诊动物、擅长病种、设备和急诊能力。
- 每次修改已发布资料后自动回到待审核，不直接覆盖公开资料。
- 只有公开资料已核验的医院才能申请广告。
- 投放看板展示曝光、详情、电话/导航、预约请求和到院核销漏斗；未接入服务器时一律显示“—”，不伪造数据。

### 开发者管理端

- 核验证照原件、发证机关、有效期、许可范围、机构地址和分支机构。
- 核验擅长方向所对应的医生、设备、服务或其他证据。
- 医院资质和广告素材分开审核；可驳回或暂停广告。
- 审核、驳回、修改、上下架、计费和数据访问都要记入不可篡改的日志。

## 禁止规则

- 广告费、竞价或佣金不得进入自然匹配分。
- 不使用“全市第一”“最好”“唯一”“100% 安全”“包治”“治愈率最高”等表述。
- 不伪造评分、评价、预约量、浏览量、病例数或到院数。
- 不展示未审核医院、过期证照或超许可范围服务。
- 广告不可伪装成匹配结果、口碑榜或“平台严选”。

## 地图和定位

第一版保留手动选城市/区域，拒绝定位时仍可完整使用。正式接入地图时：

1. 用户主动点击“找附近医院”后再展示定位告知。
2. 在应用内单独同意后才请求系统定位权限并初始化地图 SDK。
3. 默认只用使用期间/单次位置，返回结果后停止定位。
4. 若位置还要用于广告定向，这是另一个处理目的，需要另行告知与同意，同时提供非个性化广告。

## 首版商业验证

不先做“全国榜单”，而是在一个城市招募 3–5 家真实医院：

1. 免费完成资料核验和基础入驻。
2. 用真实病种搜索测试匹配质量。
3. 小额度、固定周期测试广告曝光，并显著标“广告”。
4. 只核算可追溯的真实漏斗：曝光 → 详情 → 联系/导航 → 预约 → 到院。
5. 医院能看到效果、宠主能找到适合医院、平台能持续审核后，再扩到更多地区。
