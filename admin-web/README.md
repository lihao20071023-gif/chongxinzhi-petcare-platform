# 宠馨智管理后台

这是独立于微信小程序的 React Web 管理后台。它提供两种运行方式：

- 本机开发模式：数据库尚未部署时，可直接创建你自己的本机管理员邮箱和密码，在当前浏览器真实登录并保存配置。
- 云端正式模式：Supabase 与统一 API 部署完成后，只允许数据库角色为 `platform_admin` 的账号登录，数据在不同设备间同步。

## 功能

- 真实数据看板：用户数、日活、病例数、今日护理任务完成率
- 知识库管理：结构化知识条目增删改查、审核状态和来源管理
- 医院管理：入驻申请审核、医院数据查看、公开资料核验
- 业务与数据：按宠物、护理方案、打卡、症状、检查报告、风险提醒查看真实记录量和采集用途
- 规则与提醒：AI医疗安全底线强制生效；管理员只配置提醒阈值、医生复核时限和趋势阈值

## 本地运行

1. 先根据根目录 `.env.api.example` 配好并运行统一API：`pnpm api`
2. 复制 `admin-web/.env.local.example` 为 `admin-web/.env.local`
3. 在项目根目录运行：`pnpm admin:dev`
4. 浏览器打开 Next.js 输出的网址

## 首次创建管理员账号

### 当前电脑立即使用（本机开发模式）

1. 打开管理后台。系统发现数据库未配置时，会显示“本机开发者账号模式”。
2. 填写你自己的姓名、邮箱和密码。密码至少12位，并同时包含字母和数字。
3. 点击“创建并进入后台”。密码使用浏览器 Web Crypto 的 PBKDF2-SHA256 派生值保存，不保存明文。
4. 以后在同一浏览器使用该邮箱和密码登录。业务配置与知识条目也保存在本机浏览器。

本机账号只适合开发和演示，清除浏览器数据或换电脑后不会自动同步；正式上线前必须切换到云端正式模式。

### 正式部署（云端正式模式）

1. 在后端环境变量中设置一个至少24位的随机 `ADMIN_SETUP_TOKEN`，启动统一API。
2. 打开管理后台；当数据库内还没有 `platform_admin` 时，页面会自动显示“首次创建管理员”。
3. 填写自己的管理员姓名、邮箱、至少12位且包含字母和数字的密码，以及一次性初始化口令。
4. 创建成功后会自动登录；首次开通入口永久关闭。
5. 从服务器环境变量删除 `ADMIN_SETUP_TOKEN` 并重启API。之后只使用邮箱和密码正常登录。

也可继续使用根目录的 `pnpm admin:bootstrap` 命令进行服务器端初始化。

不要把 `SUPABASE_SERVICE_ROLE_KEY` 或大模型密钥写进浏览器环境变量。云端后台网页只保存短期登录令牌，所有管理操作仍通过统一Node.js API鉴权和审计。

## 不可关闭的安全规则

以下项目不是开关，前端不提供关闭入口，统一 API 也会在保存时强制设为启用：

- AI不得独立诊断；
- AI不得新增、停用或调整药物与剂量；
- 危险信号必须优先建议联系医生或及时就医；
- 医疗回答必须引用已审核知识。
